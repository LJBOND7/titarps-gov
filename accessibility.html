Accessibility statement

Titanium Tarps LLC wants every contracting officer, small business specialist, and facility manager to be able to use this site. We build to the Web Content Accessibility Guidelines (WCAG) 2.1 Level AA as our target: semantic headings, keyboard navigation, visible focus, text alternatives for images, and color contrast of at least 4.5:1 for body text.

Known limitations

  • The downloadable capability statement PDF is generated from the HTML version. If a PDF reader does not read it correctly, use the HTML capability statement, which contains the same content.
  • Project photographs are described in alternative text but are not available as detailed descriptions.

Feedback

If you have difficulty using any part of this site or need a document in another format, email mr@titarps.com or call 305-434-0444. We aim to respond within two business days.
